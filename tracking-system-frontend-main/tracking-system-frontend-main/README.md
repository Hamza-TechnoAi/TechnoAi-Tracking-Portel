# TechnoAi PO Shipment Tracking — Frontend

React + Vite app for TechnoAi purchase order shipment tracking and staff dashboard.

## Setup

```bash
cp .env.example .env
npm install
```

Set `VITE_API_URL` to your backend (default `http://localhost:5050`).

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Vercel

Connect this repo directly. Build settings:

- Build Command: `npm run build`
- Output Directory: `dist`
- Framework: Vite

SPA routing is handled by `vercel.json`.
